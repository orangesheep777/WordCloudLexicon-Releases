口径说明（可审计）

计入后缀.kt　.kts　.ts　.tsx　.css　.mjs　.py　.ps1
根级排除android · src（Web 轨道已冻结） · dist
任意层级排除build · forensics · node_modules · .git · docs · public · artwork · .gradle · __pycache__ · captured
test 判定路径含 test / tests 段，或文件名带 .test. / Test.kt / test_
模块归属native 取包名首段 · tools 单列 · 其余按根目录名
代码 / 注释 / 空行启发式：按行首 //、/*、* 判断，块注释内整段算注释，# 仅对 .py 生效；字符串字面量里的注释符号会被误判
基线对比code-stats-baseline.json（本地文件、不入库），每次跑完覆盖；删掉它即回到「首次运行」
纯静态报告，无外部依赖 · 口径与排除清单见上一节 · 重新统计请运行 powershell -File tools/count-loc.ps1（-IncludeLegacy 可把冻结的 Web 轨道也算进来）
