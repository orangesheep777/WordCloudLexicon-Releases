# 词云煲 · 下载

把背单词做成一张会呼吸的词云。Android 版，目前处于 **beta 测试**阶段。

## ⬇️ 下载安装

**[点这里下载最新版 →](../../releases/latest)**

在 Releases 页面找到 `WordCloudLexicon-vX.Y.Z-beta.apk`，点击即可下载。

### 安装步骤

1. 用手机浏览器打开上面的链接（**不要**用微信内置浏览器，微信会拦截 APK 下载）
2. 下载完成后，点开文件
3. 系统会提示「不允许从此来源安装应用」→ 进入设置，允许该来源
4. 回到安装界面，点「安装」
5. 首次打开若提示风险，选择「仍要安装」（因为不是从应用商店下载的）

## 📱 这个 App 是什么

一个用**词云**来背单词的工具。不同于卡片式的背单词 App，它把每个单词画成词云上的一个字块：

- **字号** = 你对这个词的关注度（查得越多、记得越差，字越大）
- **颜色** = 这个词的复杂度（词长、音节数）
- **亮度** = 快忘的程度（越暗越接近遗忘，该复习了）

单词不是一个一个排队背的，而是长成一片能看见的记忆地图。

### 主要特性

| 特性 | 说明 |
|---|---|
| 词云视图 | 无限画布，可以拖动、缩放，长按还能把词拖到别处 |
| 沉浸视图 | 以屏幕中心为球核的鱼眼透镜，越靠中心越大 |
| 离线词典 | 内置 4 万+ 词条的音标、词性、中文释义、考试标签 |
| 批量导入 | 支持 `.wcl` 备份、`.csv`、`.txt`，兼容 Anki / 欧路导出的格式 |
| 完整备份 | 学习进度、收藏、词的位置都能导出成 `.wcl` 文件，换手机不丢 |
| 间隔重复 | 基于遗忘曲线的复习调度 |
| 双主题 | 明暗两套，可跟随系统 |
| 完全本机 | 不需要注册登录，所有数据只存在你自己的手机里 |

## ⚠️ 关于这个 beta 版

- 是**测试版**，功能还在迭代，界面上可能会有不完善的地方
- 用的是 debug 签名。**将来转正式版时，可能需要先卸载再安装**（学习数据会丢失）
- 建议先自己备份：设置 → 词库与数据 → 导出完整备份（.wcl）
